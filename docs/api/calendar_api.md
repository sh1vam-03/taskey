# 📅 Calendar API

Aggregated view of tasks and schedules.

**Base URL:** `/api/calendar`

---

## 1. Day View
- **Method:** `GET`
- **URL:** `/day`
- **Query:** `date=YYYY-MM-DD`

## 2. Week View
- **Method:** `GET`
- **URL:** `/week`
- **Query:** `date=YYYY-MM-DD`

## 3. Month View
- **Method:** `GET`
- **URL:** `/month`
- **Query:** `year=2024&month=5`
