# 📊 Dashboard API

Aggregated analytics and performance metrics.

**Base URL:** `/api/dashboard`

---

## 1. Overview
High-level summary of today.
- **Method:** `GET`
- **URL:** `/overview`

## 2. Today's Dashboard
Detailed timeline and stats for today.
- **Method:** `GET`
- **URL:** `/today`

## 3. Weekly/Monthly Dashboard
- **Method:** `GET`
- **URL:** `/weekly`
- **URL:** `/monthly`

## 4. Streaks
- **Method:** `GET`
- **URL:** `/streaks`
- **URL:** `/streak-calendar`

## 5. Performance Stats
- **Method:** `GET`
- **URL:** `/performance/daily`
- **URL:** `/performance/weekly`
- **URL:** `/performance/monthly`
